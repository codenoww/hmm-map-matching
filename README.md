# HMM Map Matching

Real-time map matching with a Hidden Markov Model and Viterbi algorithm,
based on the Stanford CS229 paper "Real-Time Dense Map Matching with
Naive Hidden Markov Models: Delay versus Accuracy".
UE24CS352A Machine Learning mini-project.

## Dataset
Newson & Krumm Seattle dataset. See data/README.md for download steps.

2. A different distance function in place of the Gaussian
